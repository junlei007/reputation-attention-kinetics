# WP0：模型冻结笔记（v0.1 → 定稿）

> 日期：2026-08-11。本笔记基于 WP1 数据审计（`experiments/audit.json`）与描述事实
> （`experiments/facts.json`、`figures/fig_f1..f8`）将研究计划第 7 节的"候选模型"定稿。
> 原则：**理论需要可控性，实证需要识别性，凡两者冲突之处本文记录取舍理由。**

## 1. 符号表（定稿）

| 符号 | 含义 | 取值/约定 |
|---|---|---|
| N | 全部潜在用户数（可 → ∞） | 数据中观测 5,881 |
| u_i ∈ [0,1] | 潜在类型/Graphon 位置 | 匿名潜在异质性坐标，**不是**真实社会属性 |
| B_i(t) ∈ {0,1} | i 是否已进入风险集（首次出现） | **外生**（见 §5） |
| A_ij(t) ∈ {0,1} | 有向关系 i→j 是否已发生 | 一次性，数据保证无重复有向对 |
| C_i(t) ∈ ℝ | 声誉型社会资本（主状态，一维） | 定义见 §2 |
| a(u_i,t) | 评价者活跃性 | 非负有界，piecewise constant 估计 |
| W(u,v) | 潜在类型间评价机会核 | 有界可测；数据呈核心—边缘结构（§6） |
| Ψ(C_i,C_j) | 资本依赖函数 | **有界、Lipschitz、符号自由**（§4） |
| R_ij ∈ [-1,1] | 标准化评分 = r/10 | 数据 r ∈ [-10,10] 整数 |
| Q(dr\|u_i,u_j,C_i,C_j,t) | 标记条件分布 | 符号模型 + 条件幅度模型（§4.2） |
| δ | 资本衰减率 = ln2 / 半衰期 | 基线 hl=180 天；敏感性 30/365/∞ |
| η | 跳跃归一化 = 1/10 | 单次评分 ∈ [-1,1] |

## 2. 资本定义定稿

**主状态：一维净值资本**（衰减后的标准化评分和）

C_j(t^+) = C_j(t^-) + (1/10)·r_ij，事件间 dC_j = −δ C_j dt。

**数据证据**（hl=180d 末快照，n=5,871 活跃用户）：

| 定义 | mean | skew | Gini | p99 | 负值用户占比 |
|---|---|---|---|---|---|
| count（衰减计数） | 0.29 | 12.0 | 0.835 | 4.80 | 0% |
| **net（净值，主状态）** | 0.025 | 10.6 | 0.882 | 0.84 | 16.1% |
| quality（净值/计数平滑比） | 0.004 | −2.5 | 0.744 | 0.19 | 16.1% |

- 三定义分布形态**显著不同**（count 右偏、quality 左偏），实证中不可混用；主模型用 net。
- Gini 轨迹单调上升 0.50 → 0.835（hl=180d），复现 Gargiulo et al. (2019) 的"声誉不平等上升"。
- **decision**：理论状态取一维 net；count/quality 仅作 WP5 稳健性变体，不进入主理论。

## 3. 微观生成器（定稿）

事件 i→j 在 t 时刻的强度（有序对）：

λ_ij^N(t) = (1/N) · B_i(t)B_j(t) · (1 − A_ij(t)) · a(u_i,t) · W(u_i,u_j) · Ψ(C_i^N(t), C_j^N(t))

到达时：C_j^N(t^+) = C_j^N(t^-) + (1/10)R_ij，R_ij ~ Q(dr|·)；评价者资本不变（双边更新仅作扩展）。
强度中的 1/N 使总事件率 O(1)，有限时间事件网络保持稀疏（数据：35,592 事件 / 3.5×10^7 候选对）。

## 4. 依据 WP1 事实定稿的决策

### 4.1 Ψ：有界、Lipschitz、**符号自由**（关键决策）

G1 探针（conditional logit，12,000 事件 × 30 对照，负控制全近零通过）：

| 协变量 | 系数 | p 值 |
|---|---|---|
| count_cap（衰减计数资本） | **+0.033** | 1e-30 |
| net_cap（净值资本） | **−0.064** | 2e-11 |
| log_recency（距最近一次被评） | **−1.21** | <1e-300 |
| age_days | −0.0005 | 4e-4 |
| ever_sent（发送过评价） | −0.90 | 2e-151 |

含义：**资本反馈可识别**（门禁 G1 通过，§8），且是**符号依赖**的——控制计数后，净值高的节点反而略少被选为目标。这与"负声誉追踪/再评级"一致（欺诈者被持续负面评价）。因此：

- **Ψ 不假设单调正反馈**；定稿为有界 Lipschitz 函数，符号由 WP5 结构估计决定；
- 首选参数化 Ψ(C) = 1 + α·tanh(βC) 或 logistic 型，理论只需有界性 + Lipschitz；
- 该决策同时回避了研究计划警告的无界指数优先连接。

### 4.2 标记分布 Q：符号 + 条件幅度分解

- 数据总体负评占比 10.0%，但**逐年非平稳**：2011 年 2% → 2013/14 年 14–16% → 2015/16 年 5–8%。Q 的符号部分必须带时间/协变量项；
- 幅度：|r| 分布须在 WP5 定标（截断离散分布，1–10）；
- 理论只需 Q 有界测度（弱形式不变）。

### 4.3 一次性关系排除项 A_ij：数据上的量级

- 末期候选对有 3.46×10^7，已用对 35,592，占比 **0.10%**（70% 切分点处 0.107%）；
- **decision**：主定理对无排除的潜在事件系统陈述（排除项作为显式修正），数据上排除项影响可忽略这一点为论文提供"理论假设 ↔ 数据现实"的对齐论据；
- 但排除项仍是相关性的历史来源：热门节点 + 共同目标效应（Gap 3），保留在误差分解中尝试控制（WP4）。

### 4.4 活跃性 a(u,t)：强异质性

- out-Gini 0.759 / in-Gini 0.686；corr(out,in) = 0.95；18.1% 用户从未发过评价（纯接收者）。
- 活跃性不可忽视为齐次；piecewise constant 分层估计是 WP5 主方案。

### 4.5 混合结构 W：核心—边缘而非干净分块

- 5 组谱聚类（训练期）：第 0 组 3,532 人（60%）吸收全部组间流（lift≈1），小组成对内部同质性极高（lift 6.4）；
- 对角占比 79.7%（核心内部自评主导）；
- **decision**：W 用低秩/度修正块强度估计（WP5），理论保留一般有界可测核；不预先假设分块干净。

## 5. 人口进入机制：外生风险集（定稿）

- B_i 在首次出现时刻进入风险集，**主模型无出生项**；进入率作为外生输入（数据：逐月新用户数现成，`fig_f1`）；
- 出生项（进入率 ∝ 已有资本总量）只作 WP5 稳健性扩展，不进主定理。

## 6. 宏观方程（弱形式定稿，异质核跳跃型 master equation）

对 φ ∈ C_b^1(ℝ)，u ∈ [0,1]：

d/dt ∫ φ(c) f_t(u,dc) = −δ ∫ c φ'(c) f_t(u,dc)
  + ∫∫∫ a(v,t) W(v,u) Ψ(c',c) [φ(c+ηr) − φ(c)] Q(dr|v,u,c',c,t) f_t(v,dc') f_t(u,dc) dv

- 推导中显式标注被忽略的已用关系排除项（WP3 完成完整推导）；
- 记号与计划 7.4 一致；u 为类型连续坐标，N→∞ 均场意义下成立。

## 7. 时间切分决策（重要数据事实）

- **按时间跨度 70% 切分**（计划主方案）：cutoff = 2014-07-03，训练 32,991 / 测试 2,601 事件。
  **测试期落在平台衰退尾部**（2011–13 年爆发后逐月下降，18.7 事件/天均值掩盖非平稳）。
- **decision**：主切分按计划用时间跨度 70/30（预测衰退期是诚实的强测试）；WP5 补充事件分位数切分（按事件数 70/30，cutoff 更早）与 5 个 expanding windows 作稳健性——**预测指标将按两种切分分别报告**，避免"只报简单的那种"。
- 负评比例非平稳（2%→16%→5%）⇒ Q 的时间项必要。

## 8. 门禁 G1 判定（WP1 门槛）

**结论：通过，继续资本反馈主路线。**

- 判据：资本反馈在控制活跃（ever_sent/sent_count）、节点年龄（age_days）、入度（log_indegree）后**显著可识别**（count_cap p=1e-30；net_cap p=2e-11），负控制系数近零（|β|<0.04）排除程序性伪信号；
- 不需要触发计划 WP1 门槛的降级路线（"异质活跃生成宏观信任分布"）；
- 探针局限（如实记录）：前 12,000 事件（时间上前 1/3）、case-control 30 对照近似、发送侧机制未纳入——WP5 将以完整事件似然做结构估计复检，若结果翻转则在 WP5 门禁重判。

## 9. 理论承诺范围（WP4 目标，冻结）

1. 宏观方程适定性（有界 Lipschitz 系数，Banach 不动点框架）；
2. 固定 T < ∞ 传播混沌 / 定量误差：经验测度 W1 界，目标结构
   sup E W1(μ_t^N, f_t) ≤ C_T { N^{−1/2} + d(W_N,W) + ε_history(N,T) }；
3. ε_history 先尝试显式控制（热门节点 + 已用对计数）；失败则按计划 WP4 门槛降级为"排除项 = 微观修正 + 数值误差项"，主定理针对无排除潜在系统——数据（排除占比 0.1%）为此降级提供实证背书；
4. 不承诺任意长时间（耗散性结果仅条件探索）。

## 9.5 WP2 补充定稿：Ψ 的乘法化参数化

模拟器与估计采用**乘法化**有界参数化：

Ψ(C_i, C_j) = ψ1(C_i) · ψ2(C_j)，ψ1, ψ2 有界非负 Lipschitz，如 1 + α·tanh(βC)（α 使 Ψ ∈ [1−α, 1+α] ⊂ [0, ∞)）。

理由：
1. **可分解性**：块级总强度 Λ_gg' = (1/N)·W_gg'·(Σ_{i∈g} a_i ψ1(C_i))·(Σ_{j∈g'} ψ2(C_j)) 因子化，事件驱动模拟 O(N) 精确可行；
2. **估计可识别**：发送侧与目标侧效应分离（与 G1 探针的"控制活跃后净资本条件效应为负"兼容：ψ2 可非单调）；
3. **理论不损失**：弱形式与 WP4 证明仍按一般有界 Lipschitz Ψ 陈述，乘法化只是受控子类；ψ1 ≡ 1 时退化为目标侧模型。

## 10. 冻结后遗留问题（WP5 处理）

- δ 半衰期：基线 180 天由 profile likelihood 复核（训练期预测 fit 网格）；
- Ψ 的符号与形状：结构估计 + 与探针结果对照（预计 net 系数为负）；
- recency 效应（log_recency −1.21 极强）：衰减计数资本已部分吸收；若结构诊断显示残余 recency 效应超出资本，则扩展模型（在 WP5 门禁决定，不进主定理）。
