## 1. 定理 T1：适定性（存在唯一，v0.7）

**定理。** 设 (A1)–(A4)，T < ∞。弱形式在
X_T = C([0,T]; Π_{k=1}^K P₁(ℝ))，d_T(f,g) = sup_{t≤T, k} W1(f_{k,t}, g_{k,t})
中存在唯一解，且对初值连续依赖。

**证明方案。**

1. **概率表示**：Φ(f) = 冻结系数线性方程的解测度流（特征线 + 有界跳跃率
   κ_f ≤ Λ，标记率测度 ν_{k,t}[f]）。

2. **[V1] 关键估计（v0.6 定稿：显式常数 B，无 K 因子）**：
   衰减漂移 δ∂_c(c·) 与 f 无关，在 (L_f − L_g) 中抵消。**生成元差逐点估计**
   （固定状态 c，v0.6 修正：v0.5 写成"对 f+g 积分"是多余的）：对 φ
   （‖φ‖_∞ ≤ 1, L_φ := ‖φ'‖_∞），由对偶（h_φ(∂)=0）：

   |(L_f − L_g)φ(c)| ≤ ηL_φ·D_Λ(ν_{k,t}[f](c,·), ν_{k,t}[g](c,·))。

   核心子估计（v0.6 定稿）：

   **D_Λ(ν_{k,t}[f](x,·), ν_{k,t}[g](y,·)) ≤ B(|x−y| + d_T(f,g))，B = AP(L_ψ + PL_Q)**。

   分解（常数逐项对账）：
   - ψ2 因子乘积界：D_Λ(ψ2(x)M_f(x), ψ2(y)M_g(y)) ≤ ψ2(y)D_Λ(M_f(x),M_g(y))
     + |ψ2(x)−ψ2(y)|·M_f(x)(ℝ)：外层 ψ2 差贡献 **AP·L_ψ|x−y|**；
   - 类型分解（发送混合逐分量匹配）：D_Λ(M_f(x), M_g(y)) ≤ Σ_ℓ π_ℓ a_ℓ W_ℓk
     [L_ψ·W1(f_ℓ,g_ℓ) + P·L_Q|x−y|（A3 标记 c 依赖）+ P·L_Q·W1(f_ℓ,g_ℓ)]：
     标记 c 依赖贡献 **AP²·L_Q|x−y|**，发送律差贡献 **AP²·L_Q·d_T**；
   - ψ1 项贡献 **AP·L_ψ·d_T**；
   - **Σ_ℓ π_ℓ a_ℓ W_ℓk ≤ A（Σπ=1）⇒ 无 K 因子**。
   合计 B = AP(L_ψ + PL_Q) ✓。

## 2. 定理 T2：定量传播混沌（v0.7）

**定理。** 设 (A1)–(A5)（类型 iid ~ π，初始混沌，精确初始化）。则

**证明方案。**

1. **非线性独立副本**：Ỹ_i 相互独立，率 κ_t(u_i, Ỹ_i) = A_t(u_i)ψ2(Ỹ_i)
   （A_t 仅依赖极限场 f_t），标记率测度 ν_{u_i,t}[f]；Ỹ_i(0) = C_i^N(0) a.s.。
   Law(Ỹ_i(t)) = f_t(u_i,·) ✓。

2. **同步耦合（v0.5 修正：每目标一个支配时钟）**：
   v0.4 用"每对 (i,j) 一个 Λ-时钟 + 按目标率 λ_j^N/Λ 接受"——每目标有 N−1
   个时钟，接受后总率 ≈ (N−1)λ_j^N，**多一个 N 因子**（缩放错误）。
   正确构造：**每个目标粒子 j 一个强度 Λ 的支配泊松随机测度**；时钟到达时
   从 (ν̄_{j,t}^N/Λ, ν̄_{u_j,t}[f](Ỹ_j)/Λ) 的最优 D_Λ-耦合抽 (z,z')：
   z=∂ 表示有限系统不跳，z'=∂ 表示副本不跳（墓地状态即"不跳"）。
   接受概率 λ_j^N/Λ 与 κ_t/Λ 精确 ⇒ 边际跳时不变；不同 j 时钟独立 ⇒
   副本相互独立 ✓。D_t := (1/N)Σ_i E|C_i^N(t) − Ỹ_i(t)|。

3. **[V3] 平均目标界（v0.6 定稿：精确常数）**：
   **v0.4 逐个 j 用总体平均误差 D_t 控制不充分**（某些 j 的误差可大）；
   最终形式（用户给出的结构）：

   (1/N) Σ_j E D_Λ(ν_{j,t}^N, ν_{u_j,t}[f](Ỹ_j))
   ≤ **2B·D_t + Λ·E‖π_N−π‖₁ + B·C_{q,T}·√(K/N) + Λ/N**。

   分解（类型 k = u_j，块核 W_ℓk）：
   (i) ψ2 因子：乘积界 + |ψ2(C_j^N)−ψ2(Ỹ_j)| ≤ L_ψ|C_j−Ỹ_j|（质量 ≤ AP ≤ Λ）
       → 2B·D_t 的一部分；
   (ii) 类型权重（v0.7 修正：统一为经验权重 p_ℓ^N，与随机 N_ℓ 逐式衔接）：
       D_Λ(Σ_ℓ p_ℓ^N R_{j,ℓ}, Σ_ℓ π_ℓ R̄_ℓ) ≤ Σ_ℓ p_ℓ^N D_Λ(R_{j,ℓ}, R̄_ℓ)
       + AP·‖p^N−π‖₁（墓地吸收权重差，代价 1/单位，AP ≤ Λ），乘外层
       ψ2 ≤ P 后贡献 **P·Σp_ℓ^N D_Λ(R_{j,ℓ},R̄_ℓ) + Λ·E‖π_N−π‖₁**；
   (iii) 同类型分量（发送类型 ℓ）：
     - 发送场差：类型内 iid 涨落（**随机样本量 N_ℓ**，v0.6 修正）：
       E[(N_ℓ/N)·N_ℓ^{-1/2}·1_{N_ℓ>0}] = (1/N)E√N_ℓ ≤ √(π_ℓ/N)，
       对 ℓ 求和 → **B·C_{q,T}·√(K/N)**（v0.5 直接写 N^{-1/2} 未经随机
       样本量加权——已修）；耦合差 → 2B·D_t；
     - **i≠j 排除自项**（j ∈ ℓ 时发送者集合缺 j）：单个原子质量 ≤ AP/N，
       **D_Λ(含自项, 删自项) ≤ AP²/N = Λ/N**（精确常数）→ Λ/N 项；
     - **标记差（匹配部分）沿最优输运计划的条件核配对**（v0.6 表述修正）：
       最优计划 γ^ℓ（经验发送测度 → f_{ℓ,t}）分解为从每个经验原子 x 出发的
       **条件核 π^{γ^ℓ}_x(dc')**（不假设"单个确定伙伴"——一般计划是随机配对）：
       W1(Q(·|C_i^N,C_j^N), Q(·|c',Ỹ_j)) ≤ L_Q(|C_i^N−Ỹ_i| + |C_j^N−Ỹ_j|
       + |x−c'|)（A3），沿计划 ∫|x−c'|π_x(dc') 平均 = W1(经验, f)
       → E ≤ C_{q,T}N_ℓ^{-1/2}（经验 W1 引理，步骤6；独立抽样
       E|Ỹ_i−c'| = O(1) 不可用）→ 与发送场差合并进 √(K/N) 项；
   (iv) 汇总平均 ⇒ 核心估计（⚠️ [V3] 常数逐项对账：系数 2B 与 D_Λ/TV
       关系的常数）。

4. **闭环（v0.7：补偿子公式定稿）**：时钟事件期望资本差 ≤ η·D_Λ/Λ，
   Λ 事件/单位时间 ⇒ 跳跃贡献 ≤ η∫(1/N)Σ_j E D_Λ ds；**衰减作为补偿子**：
   两次跳跃之间 Δ_j' = −δΔ_j ⇒ |Δ_j(t)| = e^{−δ(t−s)}|Δ_j(s)| ≤ |Δ_j(s)|
   （衰减不放大耦合误差），贡献 −δ∫D_s ds：

   D_t ≤ D_0 − δ∫_0^t D_s ds + η∫_0^t (1/N)Σ_j E D_Λ(ν^N_{j,s}, ν_{u_j,s}[f](Ỹ_j)) ds。

   代入平均目标界：D_t ≤ D_0 + C∫(D_s + N^{−1/2} + E‖π_N−π‖₁ + 1/N)ds
   ⇒ Grönwall：D_T ≤ C_T(N^{−1/2} + E‖π_N−π‖₁)（1/N 吸收）。

   常数，Jensen + Σ√(π_k(1−π_k)) ≤ √(K−1) 均匀时最大；v0.6 的 √(2K/(πN))
