## 1. 微观过程（冻结版，见 WP0）

N 个粒子，粒子 i 带类型 u_i ∈ {1..K}（块结构；Graphon 连续型为后续升级）、活跃性
a(u_i,t)（有界）、资本 C_i^N(t) ∈ ℝ、进入指示 B_i(t) ∈ {0,1}（外生）与已用关系
A_ij(t) ∈ {0,1}。

有序对 (i→j) 在 t 时刻的强度（WP0 §3）：

λ_ij^N(t) = (1/N) B_i B_j (1−A_ij) a(u_i,t) W(u_i,u_j) ψ1(C_i^N(t)) ψ2(C_j^N(t))

- 资本在事件间衰减：dC_j = −δ C_j dt；事件 (i→j) 到达时 C_j^N(t^+) = C_j^N(t^-) + η R_ij；
- 标记 R_ij ~ Q(dr | u_i, u_j, C_i, C_j, t)，|R| ≤ 1，η = 1/10；
- 乘法化 Ψ = ψ1·ψ2 是 WP0 §9.5 冻结的估计/模拟规格；理论可放宽为一般有界 Lipschitz。

## 2. 记号、类型比例与弱形式（v0.2 修正版）

**类型比例。** 设类型 u_i 取值 {1..K}，比例 π_k（Σ_k π_k = 1）为类型分布
（随机类型：u_i iid ~ π；或确定型经验分布 π_N，见 §2.4 的误差项）。

**条件资本测度。** 极限对象取**条件表述**：f_{k,t} = 类型 k 的资本分布
（概率测度，总质量 1，∀k, t）。类型质量 π_k 显式留在积分里，不吞进 f 的记号。
初始 f_{k,0} 给定。

**经验测度。** μ_t^N = (1/N) Σ_i δ_{(u_i, C_i^N(t))}（U×ℝ 上的联合经验测度），
类型边缘 p_k^N(t) = N_k/N（恒定，N_k = #{i: u_i = k}）。

### 2.1 单粒子动态与经验发送场

对目标粒子 j（类型 k），被评价强度：

κ_j^N(t) = ψ2(C_j^N(t)) · (1/N) Σ_{i: u_i=ℓ} B_i a_ℓ(t) W_{ℓk} ψ1(C_i^N(t))
         = ψ2(C_j^N(t)) · A^N_t(k),

其中 **经验发送场** A^N_t(k) = Σ_ℓ (N_ℓ/N) a_ℓ(t) W_{ℓk} · (1/N_ℓ)Σ_{i:u_i=ℓ} ψ1(C_i^N(t))。
若类型混沌且 μ_t^N → f_t（以 §2.4 的度量），则

A^N_t(k) → A_t(k) := Σ_{ℓ=1}^K π_ℓ a_ℓ(t) W_{ℓk} S_t(ℓ),

其中 **发送场** S_t(ℓ) = ∫ ψ1(c') f_{ℓ,t}(dc')。（⚠️ 与 v0.1 相比：类型权重 π_ℓ
显式出现——v0.1 把 f_t(v,·) 同时当"条件测度"与"联合测度"使用，π 被吞掉，
仅当类型均匀时正确。）

### 2.2 未归一化标记率核 M_{k,t}（v0.2 新增）

v0.1 的平均标记核 Q̄_t = 分子/A_t(u) 在 A_t = 0（无发送者）时无定义。修正：
定义 **未归一化标记率核**（测度值，总质量 A_t(k)，可为 0）：

M_{k,t}(c, dr) := Σ_{ℓ=1}^K π_ℓ ∫ a_ℓ(t) W_{ℓk} ψ1(c') Q_{ℓk}(dr | c', c, t) f_{ℓ,t}(dc')。

跳跃生成元写成（对 φ ∈ C_b^1(ℝ)，目标类型 k、资本 c）：

L_t^φ(k, c) = ψ2(c) ∫ [φ(c + ηr) − φ(c)] M_{k,t}(c, dr)。

归一化核 Q̄_{k,t}(dr|c) = M_{k,t}(c,dr)/A_t(k) 仅在 A_t(k) > 0 时有意义；
证明中一律用 M（测度值）论证，避免零分母。

### 2.3 弱形式（正式版）

对类型 k 与测试函数 φ ∈ C_b^1(ℝ)：

d/dt ⟨φ, f_{k,t}⟩ = −δ ⟨c φ'(c), f_{k,t}⟩
  + Σ_{ℓ=1}^K π_ℓ ∬ a_ℓ(t) W_{ℓk} ψ1(c') ψ2(c)
      [φ(c + ηr) − φ(c)] Q_{ℓk}(dr | c', c, t)
      f_{ℓ,t}(dc') f_{k,t}(dc)。

等价地（用 M 记号）：

d/dt ⟨φ, f_{k,t}⟩ = −δ ⟨cφ'(c), f_{k,t}⟩ + ∫ ψ2(c) [∫ (φ(c+ηr) − φ(c)) M_{k,t}(c, dr)] f_{k,t}(dc)。

目标率 κ_t(k,c) = A_t(k) ψ2(c)，其中 A_t(k) = Σ_ℓ π_ℓ a_ℓ(t) W_{ℓk} S_t(ℓ)。

**强形式**（跳跃型主方程，标记离散支集上求和）：

∂_t f_{k,t}(c) = δ ∂_c(c f_{k,t}(c)) − κ_t(k,c) f_{k,t}(c)
  + ∫ κ_t(k, c − ηr) f_{k,t}(c − ηr) Q̄_{k,t}(dr | c − ηr)。

**守恒检查**（v0.2）：∫dc(跳跃损失 + 增益) = 0 ⇒ 逐 k 总质量恒 1 ✓；
类型质量 π_k 为常数参数 ✓。（v0.1 中逐 u 质量"守恒但未声明归一化"的模糊消除。）

### 2.4 度量与类型误差项

W1 作用于 **概率测度**（联合测度 μ_t^N 与 f_t = Σ_k π_k f_{k,t} 都是 U×ℝ 上的
概率测度）。ground metric 取 d((u,c),(u',c')) = 1_{u≠u'} + |c − c'|。

**引理（类型-资本分解，v0.7 修正）。** 若 μ = Σ_k p_k μ_k，f = Σ_k π_k f_k
（类型边缘 p, π，条件测度 μ_k, f_k），则

**W1(μ, f) ≤ Σ_k p_k W1(μ_k, f_k) + C_T·‖p − π‖_1**

（v0.7：权重取经验类型分布 p_k——与随机 N_ℓ 的逐式计算衔接；v0.6 用 π_k
权重与后续 p_ℓ^N 不一致，已修）。证明：同类型质量 min(p_k,π_k) 按最优耦合
配对；剩余质量 (1/2)Σ|p_k−π_k| 跨类型搬运，每单位代价 ≤ 1 + 两端矩
（矩因子吸收进 C_T）。

对经验测度：E W1(μ_t^N, f_t) ≤ Σ_k p_k^N E W1(μ_{k,t}^N, f_{k,t})
+ C_T·E‖π_N − π‖_1。
**类型误差干净常数（v0.7，用户核验）**：
E‖p^N − π‖_1 ≤ (1/√N)·Σ_k √(π_k(1−π_k)) ≤ **√((K−1)/N)**
（Jensen：E|N_k/N − π_k| ≤ √(Var) = √(π_k(1−π_k)/N)；Σ_k√(π_k(1−π_k))
≤ √(K−1)，均匀分布时取最大）。
- 若类型 iid ~ π：类型项 = O(N^{-1/2})，被主项吸收；
- 若类型确定型经验分布：‖π_N − π‖_1 作为**显式误差项**保留在定理中。

**数值实践的一致性**：`experiments/micro_macro.json` 的 W1 在块设计下计算
（N_k = Nπ_k 精确、确定型分组），类型项 ≡ 0，数值 W1 即逐类型资本 W1——与
本文度量的引理上界一致（类型项为零）。

## 3. 一次性关系排除项（ε_history 的出处，v0.2 常数目标更新）

精确 N 系统强度含 (1−A_ij)：已用有向对事件率为 0。极限推导忽略该项，引入的误差：

- 每对 (i,j) 至多贡献一次事件 ⇒ 排除项只减少 **已用对** 上的强度；
- 数据度量（WP1）：训练期末已用对 35,592 / 候选对 3.46×10^7 ≈ 0.107%；
- **常数追踪**（v0.4 定稿）：令 Λ = ‖a‖_∞‖W‖_∞Ψ_max²。对粒子 j，被排除的
  强度 λ^exc_j(t) ≤ (Λ/N)·H_j(t)，H_j(t) = j 的已用入对数量（显式假设
  A_ij(0) = 0，初始无已用对）。期望：E H_j(t) ≤ E[以 j 为目标的事件数到 t]
  ≤ Λ·t（每粒子目标率有界），故
  E∫_0^T λ^exc_j(t)dt ≤ (Λ/N)·∫_0^T Λt dt = **Λ²T²/(2N)**，
  每次缺失事件直接资本代价 ≤ η（跳幅界；标记状态依赖进 L），Grönwall
  放大 e^{LT} ⇒

  **ε_history(N,T) ≤ η Λ² T² e^{LT} / (2N)**（显式常数，用户核验通过）。

  T² 来自已用对数量的累积增长（E H_j(t) ≤ Λt，积分 ∫t dt），e^{LT} 来自
  闭环不等式；两项都是"事件历史"的显式化——"显式有限 N 误差项"的含义
  （WP4 §3 交付证明）。自环：模型对 i ≠ j 求和（无自环），无需自环排除项。

## 4. 适定性条件（WP4 证明框架，v0.5 修正）

(A1) a, W 有界可测、非负；‖a‖_∞, ‖W‖_∞ < ∞（W 为 K×K 矩阵，有限类型）。
(A2) ψ1, ψ2 有界、非负、Lipschitz（‖ψ_i‖_∞ ≤ Ψ_max，Lip(ψ_i) ≤ L_ψ）。
(A3) Q 为概率核，按 1-Wasserstein 范数在 (c', c) 上 Lipschitz（常数 L_Q）：
     W1(Q(·|v,u,c'_1,c_1,t), Q(·|v,u,c'_2,c_2,t)) ≤ L_Q (|c'_1 − c'_2| + |c_1 − c_2|)，
     对任意 v, u, t。（具体化：标记分布对双方资本的 1-Wasserstein-Lipschitz。）
(A4) **δ ≥ 0**（v0.5 恢复：紧支撑已弃，δ>0 无必要）；π ∈ Δ_K；
     f_0(k,·) ∈ P₁(ℝ)（一阶矩，固定点空间要求）。
(A5) 初始混沌 + **统一 q 阶矩（q > 2）**：类型 u_i iid ~ π（或确定型 π_N）；
     给定类型下 C_i^N(0) iid ~ f_{k,0} 且与类型独立；
     sup_k ∫|c|^q f_{k,0}(dc) = m_q < ∞。
     （v0.5 放弃紧支撑：纯跳过程有限时间跳数只被 Poisson 分布控制，无确定
     性上界，紧支撑立即丢失；η/δ 是连续输入系统的上界，不适用。q > 2 矩
     下经验 W1 引理有初等证明：E W1 ≤ C_{q,m_q}·N^{-1/2}，尾积分
     ∫₁^∞√(m_q/x^q)dx = √m_q/(q/2−1) < ∞。）

**状态空间（v0.4 修正）**：X_T = C([0,T]; Π_{k=1}^K P₁(ℝ))，度量
d_T(f,g) = sup_{t≤T, k} W1(f_{k,t}, g_{k,t})。**P₂ 带 W1 不完备**
（一列二阶矩有限测度可 W1-收敛到仅一阶矩的测度），故固定点跑在完备的
P₁ 上；q 阶矩传播**单独**证明（WP4 T1 步骤4）。

**核心对象（v0.6 修正）**：有限标记率测度 ν（微观 ν_{j,t}^N、极限
ν_{k,t}[f](c,dr) = ψ2(c)M_{k,t}(c,dr)，总质量即目标率）与**墓地度量 D_Λ**：
A = ‖a‖_∞‖W‖_∞，**P = max{1, Ψ_max} ≥ 1**，**Λ = AP²**（M_f(ℝ) ≤ AP ≤ Λ、
ν_f(ℝ) ≤ AP² = Λ 都落在 D_Λ 定义域——v0.5 的 Λ = A·Ψ_max² 在 Ψ_max < 1
时 M_f(ℝ) 可 > Λ 而无定义）；ν̄ᵢ = νᵢ + (Λ − νᵢ(ℝ))δ_∂（总质量 Λ 化），
E_∂ = [−1,1]∪{∂}，ρ(r,r') = |r−r'|，ρ(r,∂) = 1；
D_Λ(ν₁,ν₂) = inf_{γ∈Cpl(ν̄₁,ν̄₂)} ∫ρ dγ。
（v0.4 的 D 有两个硬伤：不同总质量无普通耦合（Cpl = ∅）；1_{r≠r'} 不连续
（δ₀ vs δ_ε 时 D = 1+ε 不趋于 0），无法由 A3 控制。D_Λ 两者皆免：
等质量化保证耦合存在，ρ 连续保证 A3 控制匹配部分，对偶 h(∂)=0。）
**全程不归一化**（A_t(k) = 0 处 ν 是零测度）。

**命题（启发式）。** 在 (A1)–(A4) 下，弱形式在 X_T 中存在唯一解，且对初值
连续依赖。论证（v0.5 方案）：Φ(f) = 冻结系数线性方程的解测度流（概率表示）；
对 f, g，用同一初值实现（X₀^f = X₀^g a.s.）+ 每目标一个 Λ-支配泊松随机测度
+ thinning + D_Λ-标记耦合，生成元差 ≤ C₀ d_T(f,g)（衰减项在系数差中抵消），
路径差闭环得 d_T(Φ(f),Φ(g)) ≤ C₀Te^{CT}d_T(f,g) ⇒ T 小压缩，矩界延拓。
**WP4 交付完整证明。**

## 5. 进入指示 B_i(t) 的理论地位（v0.2 决策）

微观模型含外生进入指示 B_i(t)（数据中人口进入，WP0 冻结为外生风险集）。

**决策（第一篇方案，v0.2 定稿）**：主定理及所有证明**明确假设 B_i ≡ 1**
（全进入，t = 0 起；无出生项）。理由：

1. 理论对象是"资本动力学 + 传播混沌"，进入/窗口是实证层面的条件风险集；
2. 把 B_i 扩入粒子状态（"窗口状态"维度）会使状态空间变为 U×{0,1}×ℝ 甚至
   依赖候选历史的混合状态，理论工作量明显增加而首篇收益有限；
3. **RfA 窗口风险集因此不是主定理的直接实例**——它是实证构造的条件风险集
   （候选集 = 窗口开放的候选人），论文叙述上明确这一边界（WP6 已定：RfA 是
   跨场景稳健性验证，不宣称是主定理实例）。

**加强方案（后续论文/EJAM 升级）**：确定性类型暴露 b_k(t) 乘入强度
（λ 乘 b_ℓ(t)b_k(t)），弱方程相应乘 b；逐候选逐轮次的窗口需把"暴露状态"扩入
粒子状态——留给后续工作。

有源项（进入）的宏观处理保留 v0.1 的做法：ρ_t(k) δ_0(c) 源项，主定理对无源
方程陈述，估计中直接以经验进入率作输入。

## 6. 数值方案（kinetic.py 实现，已验证，无需改动）

块结构 u ∈ {1..K} × 资本格 c ∈ [c_min, c_max]^M，分裂格式：

1. **衰减步（保守 remap）**：f(t+dt, c) = f(t, c·e^{δdt}) 按分段线性密度的原函数
   精确积分；δ=0 时恒等（无数值扩散、无均值漂移）；
2. **跳跃步**：存活因子 e^{−κ(c)dt}；增益按每个标记 r 的分数格点目标双线性散布，
   源率 κ(c') 与标记 q(r|c') 在源格求值；
3. **重整化**：每类型总质量守恒（π_k）。

（注：求解器内部 A = W.T @ (activity·S) 的转置约定与本文 A_t(k) 定义一致；
π 权重在块设计中由 N_k/N 精确给出，数值无需改动——v0.2 的 π 修正只影响
形式化与定理，不影响已完成的数值验证。）

一致性验证（`scripts/04_micro_macro.py`，`experiments/micro_macro.json`）：

- 单轮 W1(μ_N^T, f_T)：N=250 → 4000 时 0.0109 → 0.0035，拟合 **W1 ≈ 0.148·N^{-1/2}**
  （地板 0.0011；2026-08-13 exclusion 改为精确 thinning 后重跑，
  旧值 0.198/0.0130→0.0040 含陈旧已用对扣除偏置）；
- 池化 W1（O(1/N) 偏置）：0.0056 → 0.0018，随 N 单调下降；
- 人均事件率轨迹：MC 与宏观相对差 2.1%；
- 效率：宏观 0.49s（与 N 无关）vs MC 2.25s/轮（N=4000），MC 成本 ~ O(N²T)。
